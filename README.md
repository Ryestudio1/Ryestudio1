照片详情里可以「带走一张明信片」：挑一张、写一句话，它把城市、日期和伊布邮票排成一张能保存下来的图。

每张照片只透出六项拍摄信息——机身、镜头、ISO、光圈、快门、城市。拍摄时间和坐标不进页面。
